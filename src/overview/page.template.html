律动柱头
概念演变当前构造控制逻辑Arduino接线实体小样演示与下载

从一滴水，
到会回应压力的柱头

把一次局部扰动，转译为许多颗粒共同的变化。概念来自水波纹；目前的实现候选是平顶受压、磁场接力、铁珠升降。

这页串起从概念到构造、电控与小样的完整过程。当前采用8条放射状弧底透明薄腔、1只中央大线圈和8只端部小线圈，由Arduino统一触发。

整理于2026年11月1日 · 已有数字演示与电控方案，实体运动待验证

方案是怎样一步步形成的

查看最初的水波纹演示

一路保留的是“整体固定、内部运动、对外界输入作出回应”；变化的是颗粒材料、运动约束，以及磁场怎样接近颗粒。

  1. 水滴与涟漪

    一次局部冲击，引出回弹、向外传播与衰减。先用水面理解“一个输入如何影响整体”。

    这是形态与动力概念。早期演示采用简化阻尼波模型，并非真实水面或磁场求解。

    水波纹 V4

  2. 把波纹转译为颗粒起伏

    固定柱头外壳，颗粒只上下移动。V6曾用20×20共400个受约束单元，观察由柱身连接处向上的扰动。

    这条路线关注邻域传播；模型中的传播系数与反向脉冲不能直接当作真实磁力。

    早期半球 V6

  3. 改为铁珠，尝试一只中央线圈

    希望用统一变化的磁场驱动很多小铁珠，减少逐颗执行器与接线。

    中央线圈远处的吸引不足、珠群结团和剩磁释放成为关键问题，单纯增加电流不能保证整机大行程。

    简化驱动的探索

  4. 透明浅腔，再转向竖向薄腔

    先探索浅腔里的周期展开、收拢，再把运动平面竖起来，使通电吸引与重力落回形成明显升降。

    薄腔限制前后乱动，让运动可观察；它本身不会自动解决磁力和摩擦问题。

    确定运动约束

  5. 薄腔随柱头的圆弧收底

    8片竖向透明薄腔以45°间隔放射布置，下缘随弧底收向柱身，保留半球柱头的轮廓。

    R130外壳、R126弧底是外形约束，长距离整腔吸起尚未得到实体证明。

    弧底与整机演示

  6. 增加8只端部小线圈

    中央大线圈先开，端部小线圈随后开；再依次关大、关小，尝试让珠群在中央与端部之间迁移并落回。

    大小线圈轴线都沿竖直Z方向，小线圈放在分支外端；8路同步，不逐颗指定运动。

    接力与时序滑块

  7. 平整顶面，内藏压力输入

    把传感器藏到顶板下方，通过HX711把压力信号交给Arduino，再由驱动模块控制1大8小。

    上面保持连续平面；HX711与控制器放到底座，传感器承压路径与磁骨架分开。

    当前压力交互方案

“涌现”在这里指什么

目标是让大量铁珠在简单的磁场规则、重力和相互接触作用下形成整体变化。现在的电控规则已经很简单，但8个分支同步启动，以及画面里出现波纹，都不足以证明实体涌现。是否存在由颗粒相互作用产生的传播，需要用小样和对照实验区分。

当前构造：平顶、弧底、8个分支

旋转查看三维布置

从顶面到柱身

平整PC顶板下方依次设置承压弹簧、非磁压头和LLB130。力经独立支座进入柱身，线圈和磁骨架固定在另一条路径上，减少磁吸反力对测力的影响。

中央区域预留约24mm夹层；传感器不夹在铜绕组中。周边导向让整块顶板轻微下沉，保持顶面为一个平面，下面设限位。

放大平顶传力剖面

从磁场到铁珠

8条竖向薄腔围绕柱心展开，底部随圆弧收拢。中央M0和外端S1—S8的轴线均竖直，通过通断改变工作区域。

低功耗的方向是让有效磁极接近珠群、缩小气隙，并试验回磁路径。现有径向软铁件作为可拆试件，最终磁路还未定型，不能预设9只线圈互不影响。

最简单的控制逻辑

看完整压力与信号动画

上部受压 → 传感器 → HX711 → Arduino → 驱动模块 → 线圈通断 → 铁珠运动。Arduino发指令，外置电源给线圈提供能量。

全部断电，铁珠依靠重力落回弧底，准备下一轮。

可点击任一阶段查看。这里的播放时间用于讲解，不是实体通断时间。

轻按、长按、松手

  • 轻按达到阈值，启动一轮。
  • 持续受压，整机按同一顺序循环。
  • 持续按压后松手，保留两轮间隔更长的收尾，再停止；短按只一轮。

动画2.8秒，实体先从4秒起步

当前实体程序默认四段为0.8秒大单独、0.3秒重叠、0.3秒小单独、2.6秒全断，最快周期4秒；较轻的压力还会增加间歇。

2.8秒保留为模型演示与后续试验选项。必须先确认珠群能起吸、释放和落稳，再缩短间隔。

展开74HC244针号与驱动模式

244的20脚接5V，10脚GND，1和19脚OE接GND；20与10脚就近接100nF。D10同时接2、4、6、8、11、13、15、17脚；18、16、14、12、9、7、5、3脚分别输出到S1—S8。D10总线另加10kΩ下拉。

每块DRV8874 #4035：PMODE和SLEEP接5V；PH/IN2、IMODE直接接GND。保留CS原板2.49kΩ；VREF另接Rd至GND，首次统一560Ω。VM侧就近配置470µF/35V、100nF和SMCJ18A。完整接法与后续限流档见驱动详图，不能只接IN1、VIN就通电。

最简试验夹具

透明板两片约50×35×1mm，隔框留35×20mm窗口，前后净隙2.6mm，局部弧底随R126。Ø2铁珠按1→5→20颗递增。

极面先从5mm距离测起，再测10、15、20mm；初步观察是否能重复上移10mm并落回。近距离成功后，还须回到最终磁极位置复验。

这是小窗口试验夹具，不能直接当整条弧底薄腔的加工图。

线圈与功耗先保守

M0试绕600匝、铜裸线Ø0.50mm，S试绕300匝、Ø0.30mm；轴线保持竖直。匝数和线径是试制起点。

先用560Ω的VREF下拉低流档，再按测得的吸力和温升逐级调整。此前按试绕与占空比估算的平均输入预算约10—15W，尚非实测功耗。

远处吸不起时，先调整极面、气隙与回磁试件，不用不断升流替代磁路验证。

从空载到整机的验收顺序

  1. 逻辑：先不接线圈，确认D9/D10四阶段及故障关断。
  2. 单路：低流测试每只线圈，记录电流、释放与温升。
  3. 单腔：少量铁珠，带标尺录视频，确认重复位移与落回。
  4. 压力：安装后去皮、加已知砝码标定，再测空压时开关线圈是否造成误触发。
  5. 扩展：最终磁极位置验收后，再逐级增加到8腔；模型中的1600颗暂不作为验收目标。
Arduino程序怎样启用

程序下载包内含CapitalPrototype.ino与两个头文件，无第三方HX711库依赖。串口115200，先完成基准和砝码标定，再手动启用；没有连接或烧录到实体Arduino。

t                 // 在正常顶板静载下记录基准
k 4.903325        // 已增加0.5kg砝码，求标定比例
p 1.2 0.5         // 增压启动/释放阈值，单位N
r 4000            // 最快周期4秒，首轮默认
a                 // 移去砝码、回到基准后启用
x                 // 立即停止

首次低流、传感器标定和保护检测步骤见实施包。Arduino只给HIGH/LOW指令；真实安培值由驱动硬件设置。压力、数据超时或硬件故障异常时，程序关闭输出并锁存。
