# 半球柱头：柱身向上输入与颗粒涟漪

运算化设计课程的交互形态研究。首页为 V6：固定半球柱头，20×20 共 400 颗单元，水滴式脉冲从柱身连接处向上进入，颗粒仅作竖向位移。

- 正立面、侧立面、轴测辅助视角。
- 连接处上冲、反向回弹、向上扩散与衰减。
- 冲击强度、衰减、播放速度、邻域耦合开关。
- 力学、照度、温度、湿度模拟输入与阈值触发。
- `archive/` 保留 V3、V4、V5 演示，便于比较设计演变。

## 模型范围

这是固定邻接图上的简化位移模型，不是完整磁场、流体或结构求解。脉冲、回弹、行程限位与传感器映射均为设计假设，尚未实体标定。传感器输入来自页面模拟，未连接硬件。

水滴符号表示向上输入的控制脉冲，不表示真实液滴逆重力上升。颗粒实际避让、导轨摩擦、磁极配置、驱动功率及温升需要实体试验。

## 本地运行

需要 Python 3；运行检查另需 Node.js。

```sh
python scripts/build.py
node scripts/check.cjs
python -m http.server 8000
```

然后打开 `http://localhost:8000/`。

## 更新与发布

1. 修改 `src/engine.js`、`src/app.js` 或 `src/page.template.html`。
2. 运行构建与检查，确认生成的 `index.html` 同步更新。
3. 提交并推送到 `main`。

GitHub Pages 使用 `main` 分支根目录发布。`.nojekyll` 保持站点作为纯静态 HTML 提供。所有主页面脚本内嵌，无第三方前端依赖。
