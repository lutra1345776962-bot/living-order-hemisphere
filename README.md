# 半球柱头：大小线圈顺序接力

首页更新为8个弧底透明薄腔、1只中央大线圈和8只端部小线圈的三维动态示意。9只线圈绕组平面均水平，轴向均为竖直Z；小线圈中心位于R118。

- 默认每腔200颗铁珠，整机1600颗；数量滑块可设每腔50至400颗，整机400至3200颗。
- 四个时长滑块分别调整大线圈单独、大小重叠、小线圈单独、全部断电间隔；步长0.1秒。
- 默认大/小线圈相对电流1.8×/1.6×，可调0.5×至2.5×；默认周期2.8秒，保留5.3秒、8.6秒和12秒对照；数量调节保留时序设置。
- 整机和单腔放大视图共享粒子状态，支持旋转、缩放、暂停、周期进程与弱吸力条件。
- 高数量时有每帧计算预算，优先保持控件响应，模型播放可能慢于墙钟时间。

这是磁吸代理、重力和接触计算的条件示意，未求解真实磁路、剩磁、摩擦和温升。时序、数量及位移不能作为硬件吸力或动作时间验证。页面内400颗比较表是历史时序数据，不代表所有新增数量经过相同筛选。

## 本地运行与更新

维护源为`src/engine.js`、`src/app.js`和`src/page.template.html`。在本目录执行：

```sh
python scripts/build.py
node scripts/check.cjs
python -m http.server 8000
```

## 上部受压，Arduino信号链

[三维信号链交互页](press-interaction.html)保留连续平顶、内藏测力元件、1只中央M0＋8只外端S线圈与弧底放射薄腔。底部明确布置HX711、经典5V Arduino Nano、74HC244缓冲器、M0驱动、8路S驱动和5V降压六个模块。

动态显示桥式模拟信号→HX711采样→DT至D3/D2反向时钟→Arduino判断→D9控制M0、D10经缓冲分配到8路S。逻辑、电源及回线分开表示，亮点显示方向，读数/高低电平与线圈状态共用同一模型。右侧可选电子接线、传感器剖面或铁珠分支。

“放慢信号过程”默认开启，分两段各0.35秒叙事展示后交给控制模型；这不是实际传播/ADC延迟。界面未连接实体Arduino。关闭该选项恢复直接模型输入。默认1600珠，可调400–3200；四段时长、相对电流及剖切/旋转保留。缓存固定几何，粒子和信号持续更新。

上部荷载增量统一触发整机；大开→小开→大关→小关，8只端部线圈同步通断。短时加载一轮，持续受压共同循环，卸载后两轮间歇余波再停止。保留1600颗默认数量（400–3200可调）、四段时长、相对电流、视角及分支放大。相对电流不是安培值。

维护源：`src/press-interaction/engine.js`（粒子、压力、信号队列、共享接线与原几何）与`app.js`（交互/绘制），`page.template.html`为页面；构建：`python scripts/build-press.py`。本地分模块源及检查在`Arduino信号链三维_20261031/`。原首页不变。

8个分支复制一个腔的定性轨迹来展示统一触发，非磁路/实体试验；升程、2.8 s实体周期、功耗及内藏后的电磁/温度干扰均未验证。测力元件与承压座是功能占位，非承重节点设计。上一版[单腔按压小样](single-chamber-press.html)保留供参考。
