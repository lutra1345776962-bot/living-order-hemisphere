关键接线

总图的文字对照。电源与线圈动力线经外部端子，面包板只承载5V逻辑和信号。
线路从哪里接到哪里
四线传感器LLB130红E+、黑E−、绿S+、白S−，分别至HX711的E+、E−、A+、A−。
采样与时钟HX711 DAT → Nano D3；Nano D2 → HX711 CLK。VCC、VDD接逻辑5V，GND接公共地。
中央M0Nano D9 → 220Ω → M0驱动IN1；IN1用10kΩ下拉至GND。OUT1、OUT2接本路线圈两端。
8个分支同步D10接74HC244的2、4、6、8、11、13、15、17脚。18、16、14、12、9、7、5、3脚分别经独立220Ω至S1—S8的IN1，各加10kΩ下拉。
缓冲器供电74HC244的20脚接5V；1、10、19脚接GND；20与10脚之间放100nF旁路电容。图内A/Y编号按S1—S8配对命名。
故障与温控9块驱动的开漏FAULT并接Nano D4，4.7kΩ上拉5V。9只NC50℃温控串联至D5与GND，D5用4.7kΩ上拉5V。
动力电源12V / 5A适配器 → T5A总保险 → NC急停 → 各驱动VIN；M0分路T2A，S分路各T1A。所有GND共参考，功率回流用独立导线回电源。
逻辑电源总保险后分支 → T0.5A → D24V10F5降压 → JP1 → Nano 5V及逻辑模块。使用USB供电调试时拔下JP1，Nano VIN不连接。
以下设置须逐块应用于全部9块Pololu #4035。位置按端子名称识别，不按图中方位认针。
DRV8874端子连接与设置
PMODE、SLEEP接JP1后的逻辑5V，采用IN/IN控制模式。
PH/IN2、IMODE直接接GND；IMODE使用固定关断时间调流模式。
EN/IN1D9或对应74HC244输出 → 220Ω → IN1；IN1另接10kΩ至GND。
VREF限流保留原板10kΩ至SLEEP的上拉。增加Rd至GND，首次各路均用560Ω；试验后M0计划5.11kΩ，S计划1.58kΩ，对应典型调流阈值约1.5A、0.6A。
CS保留原板2.49kΩ至GND的电阻；不使用原板默认大电流限流值。
VM保护驱动附近的VM至GND并联470µF / 35V、100nF / 50V、SMCJ18A。电解正极接VM；TVS阴极接VM，阳极接GND。
VIN、OUT1/2、FAULTVIN接本路保险后的12V；OUT1/2只接本路线圈；FAULT接公共F线至D4。

这是模块端子电路图，表达电气连接；模块位置和走线长度为排图需要。驱动的模式、限流和VM保护以详图为准，实体装置的磁力、动作时间和温升仍需小样验证。
